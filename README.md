# Ntsp-objective-
# 🚀 NTSP Objective Test Platform

## 📖 About the Project
यह एक वेब एप्लिकेशन है जिसे विशेष रूप से कक्षा 12 (BSEB/Board Exams) के छात्रों के लिए ऑब्जेक्टिव प्रश्नों के अभ्यास और तैयारी के लिए डिज़ाइन किया गया है। यह प्लेटफ़ॉर्म छात्रों को उनके सिलेबस के अनुसार टेस्ट देने और अपनी तैयारी जाँचने की सुविधा देता है।

**🔗 [Live Demo: NTSP Test App](https://ntps-objective-test.web.app/)**

## ✨ Key Features
* **Chapter-wise Mock Tests:** 12वीं के महत्वपूर्ण विषयों के लिए सटीक ऑब्जेक्टिव टेस्ट सीरीज़।
* **Instant Evaluation:** बिना पेज रीलोड किए तुरंत टेस्ट रिज़ल्ट और स्कोरिंग (Client-side validation)।
* **100% Responsive UI:** मोबाइल फर्स्ट डिज़ाइन (Mobile-first design) जो हर स्क्रीन साइज़ पर बेहतरीन काम करता है।

## 💻 Tech Stack & Architecture
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Deployment:** Firebase Hosting
* **Development Environment:** Acode Editor & Termux (Android CLI)

## 🛠️ The Developer's Flex (How it was built)
> **"No PC, No Excuses."** 
> इस पूरे एप्लिकेशन का आर्किटेक्चर, कोडिंग और सर्वर डिप्लॉयमेंट बिना किसी डेस्कटॉप कंप्यूटर के, पूरी तरह से एक एंड्रॉइड स्मार्टफोन पर Acode और Termux का उपयोग करके किया गया है। यह साबित करता है कि मजबूत 'लॉजिक' किसी महंगे हार्डवेयर का मोहताज नहीं होता।
